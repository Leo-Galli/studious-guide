Multiplayer VR Room
Spazio condiviso con sincronizzazione via WebSocket
Controlli
Desktop: WASD/frecce per muoverti, QE su/giu, R reset vista.
VR: stick sinistro muove, stick destro ruota e sale/scende.
Grilletto sinistro: invia un impulso di colore al cubo condiviso.
Prerequisito: avvia il server con npm run wss:server.
